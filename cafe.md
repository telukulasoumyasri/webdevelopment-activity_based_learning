# Blush & Butter Bakery Website

A simple, responsive bakery website built with **HTML and CSS**. Blush & Butter showcases cakes, pastries, cookies, and seasonal offers with a soft lavender and blush-pink visual theme.

## Features

- **Homepage:** Welcome section, featured sweet treats, product prices, and a link to offers.
- **Menu page:** Displays cakes, pastries, and cookies with descriptions and prices.
- **Offers page:** Highlights bakery promotions, including a first-order discount and special deals.
- **Consistent styling:** Shared design elements such as navigation, product cards, buttons, and footers.
- **Responsive layout:** CSS adjusts the header and page spacing for smaller screens.
- **Product imagery:** Uses images hosted by Unsplash.

## Technologies Used

- HTML5
- CSS3

## Project Files

| File | Purpose |
|---|---|
| `Cafe_homepage.html` | Main bakery homepage |
| `Cafe_homepage.css` | Homepage styling |
| `Cafe_menu.html` | Bakery menu page |
| `Cafe_menu.css` | Menu page styling |
| `Cafe_offers.html` | Offers and promotions page |
| `Cafe_offers.css` | Offers page styling |

## Getting Started

1. Download or clone the project files.
2. Keep each HTML file and its corresponding CSS file in the same folder.
3. Open `Cafe_homepage.html` in a web browser.
4. Use the navigation links to explore the available pages.

## Pages and Content

### Homepage
- Introduces Blush & Butter.
- Features Chocolate Cake, Berry Cream Treat, and Butter Pastries.
- Displays a first-order offer.

### Menu
- Lists Chocolate Truffle and Berry Bliss Cake.
- Lists Butter Croissant and Choco Chip Cookies.
- Shows descriptions and prices.

### Offers
- **First Order Treat:** 10% off the first order with code `BLUSH10`.
- **Cookie Lover's Box:** Six cookies for ₹350.
- **Celebration Special:** A free birthday message card with custom cake orders.

## Design

The website uses a soft pastel palette:
- Lavender and light purple
- Blush pink
- White product cards
- Deep purple text and footer

The CSS uses Flexbox for the header, CSS Grid for product galleries, hover effects for links and buttons, and a media query for smaller screens.

## Notes

- The homepage and menu include links to `Cafe_custom.html` and `Cafe_contact.html`, but those files were not included in the supplied project files. Add those pages or update the links if needed.
- Product images require an internet connection to load from Unsplash.
- This project is a front-end demonstration; no backend, ordering system, or payment processing is included.
