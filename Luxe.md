# LUXE LANE

**LUXE LANE** is a front-end fashion and lifestyle e-commerce website
concept built with HTML and CSS. It presents a clean, elegant storefront
where visitors can explore products, browse categories, view product
details, and see sample promotional offers.

> **Project note:** This is a demonstration website. Product details,
> prices, ratings, discounts, and coupon codes are sample content. It
> does not process real orders or payments.

## Features

-   **Home page** with a hero section, featured products, and
    promotional banner.
-   **Shop page** displaying a product grid with category labels,
    prices, ratings, and discount tags.
-   **Categories page** featuring Fashion, Accessories, Beauty, and
    Lifestyle.
-   **Product details page** with product images, pricing, ratings,
    product information, and related items.
-   **Offers page** showcasing sample deals and a demo coupon code
    (`LUXE10`).
-   **Cart page** included in the site navigation.
-   Consistent visual theme using deep green, warm beige, and gold
    accents.
-   Responsive layout styling for different screen sizes.
-   Product photography loaded from Unsplash and fonts loaded from
    Google Fonts.

## Technologies Used

-   **HTML5** for page structure and content.
-   **CSS3** for styling, layout, grids, typography, and responsive
    design.
-   **Google Fonts** for typography.
-   **Unsplash** for sample product and lifestyle images.

## How to Run the Project

1.  Download or clone this repository.

2.  Keep all HTML and CSS files in their existing folder structure.

3.  Open `luxe_homepage.html` in a web browser.

    Alternatively, open the project folder in Visual Studio Code and use
    a local preview extension.

No package installation or build step is required for this static
front-end project.

## Important Notes

-   The site is a front-end demonstration and is not connected to a
    database or payment gateway.
-   The offers and coupon code are examples only; no real discount is
    applied.
-   Product images and Google Fonts require an internet connection.
-   Check that file names and links match exactly, including
    capitalization and spelling, because some hosting platforms use
    case-sensitive paths.
-   The navigation currently uses the project's existing filenames. If
    you rename any file, update the related links in the HTML.
